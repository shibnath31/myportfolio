## 📖 About

Welcome to my **Personal Portfolio Website**! 🚀

This portfolio showcases my skills, projects, education, certifications, and contact information. It is designed with a modern, responsive interface to provide visitors with an engaging experience across all devices.

- 🎨 Modern and Clean UI

### Clone the repository

```bash

```

### Navigate to the project

```bash

```

### Open in browser

```
index.html
```
